# E-Commerce QA Automation Project

## 1. Project Objective

The objective of this project is to test the SauceDemo E-Commerce application using manual testing and automation testing techniques.

The project covers functional testing, UI testing, API testing practice, and automated regression testing.

## 2. Application

- Application Name: SauceDemo
- Application URL: https://www.saucedemo.com/

## 3. Modules

The following modules are covered:

- Login
- Products
- Product Details
- Cart
- Checkout
- Order
- Logout

## 4. Technologies and Tools

- Java
- Selenium WebDriver
- TestNG
- Cucumber
- Maven
- Postman
- Git and GitHub
- Jira
- Jenkins
- Eclipse IDE

## 5. Automation Framework

The project uses the Page Object Model (POM) design pattern to organize page elements and actions separately from test logic.

The framework includes:

- Page classes
- Test classes
- Cucumber feature files
- Step definitions
- Test runner
- Configuration properties
- Explicit waits
- Test listeners
- Retry analyzer
- Extent Reports
